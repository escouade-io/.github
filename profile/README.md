# Escouade

*Français plus bas.*

## English

**Escouade** is a software family for French companies: one account, one subscription, and your company's knowledge ready for your AI agents. Escouade (CRM, documents, agents) works online or on your own server; **Meet** writes the minutes of your meetings, **Mail** gives real mailboxes to your team and your agents, **Social** publishes on LinkedIn, **Tools** opens free PDF, photo, vector and layout tools.

The public repositories here are the open clients of **Escouade Mail** (formerly Subagent), MIT licensed:

| Repository | What it is |
| --- | --- |
| [escouade-mail-mcp](https://github.com/escouade-io/escouade-mail-mcp) | Connect the MCP server to Claude Code, Cursor or any MCP client |
| [escouade-mail-python](https://github.com/escouade-io/escouade-mail-python) | Python SDK (`pip install escouade-mail`) |
| [escouade-mail-node](https://github.com/escouade-io/escouade-mail-node) | TypeScript SDK (`npm install escouade-mail`) |
| [escouade-mail-cli](https://github.com/escouade-io/escouade-mail-cli) | Command line (`npm install -g escouade-mail-cli`) |
| [escouade-mail-skills](https://github.com/escouade-io/escouade-mail-skills) | Skills for AI agents |
| [escouade-mail-plugins](https://github.com/escouade-io/escouade-mail-plugins) | Claude Code plugin |
| [escouade-mail-examples](https://github.com/escouade-io/escouade-mail-examples) | Runnable examples, Python and Node |

- Website: https://escouade.io
- Documentation: https://escouade.io/docs · Escouade Mail: https://escouade.io/mail/docs
- Contact: contact@escouade.io

## Français

**Escouade** est une famille de logiciels pour les entreprises françaises : un compte, un abonnement, et le savoir de votre entreprise prêt pour vos agents IA. Escouade (CRM, documents, agents) s'utilise en ligne ou sur votre propre serveur ; **Meet** écrit le compte rendu de vos réunions, **Mail** donne de vraies boîtes mail à votre équipe et à vos agents, **Social** publie sur LinkedIn, **Tools** ouvre des outils gratuits pour le PDF, la photo, le vectoriel et la mise en page.

Les dépôts publics sont les clients ouverts d'**Escouade Mail** (ex-Subagent), sous licence MIT : serveur MCP, SDK Python et TypeScript, ligne de commande, recettes pour agents, plugin Claude Code et exemples (tableau ci-dessus).

- Site : https://escouade.io
- Documentation : https://escouade.io/docs · Escouade Mail : https://escouade.io/mail/docs
- Contact : contact@escouade.io
